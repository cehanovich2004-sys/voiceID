# Architecture Decision Records

This directory stores Architecture Decision Records for VoiceID.

Use ADRs for decisions that affect project structure, dependency strategy,
runtime requirements, model choices, biometric handling, or public behavior.

Recommended format:

```text
ADR-XXX: Title

Status:
Decision:
Alternatives:
Reason:
Consequences:
```
